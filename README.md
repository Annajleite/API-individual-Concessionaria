# API Concessionária

Projeto desenvolvido para o trabalho individual de Backend, para a matéria de API RESTful Serratec, o gerenciamento de clientes e veículos de uma concessionária.

## O que eu usei
- Java
- Spring Boot
- PostgreSQL
- Spring Data JPA
- Swagger (OpenAPI) para documentação

## informações uteís 
- Configura o PostgreSQL
- Rode o projeto pela classe `ApiApplication` (usei pelo intellij)
- Acesse a documentação do Swagger no navegador: `http://localhost:8080/swagger-ui/index.html`
